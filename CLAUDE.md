# МПКА 2 — «Курчатов vs Москва»

Своя MOBA в духе Dota 2. Две стороны: **Курчатов** (синие, `Team.Kurchatov`, база внизу слева) и **Москва** (красные, `Team.Lobnya`, база вверху справа). Всё в игре — на русском, шутки «про своих» (пицца, шаурма, пивная баня, гопники в лесу).

Есть **две версии**, их надо держать одинаковыми по фичам:

1. **ПК — Unity** (этот проект, `Assets/`). Unity **6000.6.7f1**, URP, Input System, NavMesh (AI Navigation), интерфейс на **IMGUI** (`OnGUI`).
2. **Телефон / браузер — HTML5 Canvas** (папка `WebVersion/`). Один JS-файл игры, собирается в один HTML. Опубликована как артефакт claude.ai: https://claude.ai/artifact/8G4J4jfCG3wFLrw6ZJTMbv (обновлять — только через claude.ai, из Claude Code просто собирай файл).

Пользователь — школьник/начинающий разработчик, общается по-русски, коротко. Отвечай по-русски, без длинных простыней. Фото друзей в игре — по просьбе пользователя (лица героев, курьер).

## Unity: как собрать и запустить

- После изменения скриптов: в Unity **Ctrl+R** (Refresh).
- Если менялись билдеры в `Assets/Scripts/Editor/` (карта, герои, башни) — **пересоздать карту**: `Tools → MOBA → «Создать карту Курчатов vs Москва»`. Главное меню: `Tools → MOBA → «Создать главное меню»`.
- Запуск: Play из сцены `MainMenu` → «ИГРАТЬ» → «ПРИНЯТЬ» → лобби (выбор героя → линия → стартовый закуп) → бой.
- Сцена карты собирается целиком кодом (`MapBuilder`), руками в сцене ничего не правим — правим билдеры и пересоздаём.

### Структура `Assets/Scripts`
- `Core/` — `MatchSetup` (лобби 5×5, спавн героев из выключенных шаблонов, верхняя панель как в Доте, карточка героя по клику на портрет, таблица счёта на **Ё** (пока зажата), У/С/П + добито/денаи слева сверху, лента убийств, `MatchTime`), `FogOfWar` (туман, временное зрение `AddVision`/`Reveal`), `Glyph` (G, 5 сек неуязвимости строений и крипов, КД 120), `LaneData` (3 линии + лес, координаты башен и лагерей), `GameManager` (пауза/победа).
- `Heroes/` — `HeroCatalog` (все цифры героев и способностей: `HeroDefinition`, `AbilityInfo`), `HeroStats`, `HeroProgress` (опыт, золото, пассивное золото 1.6/сек), `HeroController` (управление игрока, приказы, воскрешение), `BotHeroAI` (боты: линия/лес, драки, отступление, магазин, глиф, денай, электричка домой; первые 40 сек не лезут в драку).
  - `Sanya/` — Саня Финд (сосиски, колбасные койлы Q/W/E с общим уровнем, реквием R), `VoiceLines` (голос героев из `Resources/Voice/<id>/lineN.wav`).
  - `MaxGold/` — Макс Gold (снайпер: Q Золотой дождь в точку с 3 зарядами, W Голдшот пассивка, E Лестница Габилджона, R Хантерас пик). `MaxGoldKit` — дальность от E, лестница, голдшот, голос (смерть = line6).
- `Abilities/` — `Ability` (база + `AbilityFactory` по id), `AbilityCaster` (Q/W/E/R, цели: юнит, без цели, **точка**, заряды), `OgrMogAbilities` (Огр Mog: пицца, соус, энергетик, ульта-мультикаст).
- `Units/` — `Unit`, `Health` (урон, `AnyDeath`/`AnyDamaged`, шаурма сбивается от урона героя/башни), `Mana`, `StatusEffects`, `AutoAttack` (автоатака, приказ «иди» отключает автоатаку до прихода, анти-застревание в толпе, туман), `Courier` (курьер у **каждого** героя: тайник → герой, F; фото лица — только у курьера игрока; `Courier.Of(hero)`; улучшение «Самокат курьеру» `courier_scooter` 150 золота — скорость 12, 450 HP, модель на самокате).
- `Items/` — `ItemCatalog` (все предметы), `Inventory` (6 слотов + рюкзак 3, **слот билета на электричку** `TpCharges` до 5, **тайник** `Stash` для покупок вдали от бани), `ItemEffects` (активки 1–6, **T — электричка** к своей башне/трону/бане, двойное T — в баню, КД 40), `ItemIcons`.
- `Creeps/` — крипы по 3 линиям, лесные лагеря гопников (`JungleManager`, `NeutralAI`).
- `Structures/` — `Tower` (при разрушении проваливается под землю, снимается `NavMeshObstacle`), `Throne`, `Protected` (трон открывается после любой 2-й башни), `BeerBath` (лечит), `Projectile` (шар/диск/золотая пуля).
- `UI/` — `AbilityBarGUI` (нижняя панель: портрет, скиллы с иконками, инвентарь, слот электрички), `MinimapGUI`, `ShopGUI` (B; вдали от бани — в тайник), `MainMenu`, `HealthBarGUI`, `TouchInput`, `HudArea` (зоны интерфейса, чтобы клики не уходили в мир).
- `Editor/` — `MapBuilder`, `HeroBuilder` (модели героев из примитивов, лица — картинки на billboard), `TowerBuilder`, `BathBuilder`, `DecorBuilder`, `MenuBuilder`, `WebBuilder`.

### Ресурсы
`Assets/Resources/`: `Items/` (иконки предметов), `AbilityIcons/` (иконки способностей Макса, по id), `Portraits/` (`ogr_mog_l/r`, `sanya_fiend`, `max_gold`), `Voice/sanya_fiend`, `Voice/max_gold` (wav), `Courier/` (лицо и портрет курьера). Лица для моделей — `Assets/Textures/Face_*.png`.

### Грабли (уже наступали)
- В Unity 6 `Object.GetInstanceID()` — **ошибка компиляции** (obsolete). Не использовать.
- `FindObjectsSortMode` / `FindFirstObjectByType` — только предупреждения, не страшно.
- Не вставлять реальный перевод строки внутрь строкового литерала C# (было «Newline in constant»). Только `\n`.
- Перекомпиляция во время Play ломает статические поля (туман уже защищён). Перед правками — остановить Play.
- Изменил билдер → без пересоздания карты изменений не будет.
- Unity Hub любит всплывать поверх окна Unity.

## Веб-версия (`WebVersion/`)

- `game.js` — вся игра (≈2300 строк): данные героев/предметов, мир, бой, способности, боты, отрисовка на Canvas, HUD, лобби, меню, курьер, электричка, счёт.
- `shell.html` — разметка и CSS (HUD, меню, лобби, магазин).
- `images.js`, `itemimg.js`, `sounds.js`, `maximg.js`, `courierimg.js` — картинки/звуки в base64.
- **Сборка:** `python build.py` → `mpka2.html` (для публикации артефактом) и `test.html` (полный документ для тестов и офлайна).
- **Тесты** (Node + Playwright, `npm i playwright` и `npx playwright install chromium`): `node tests/mob_test.js`, `node tests/max_test.js`, `node tests/sim5.js` — гоняют матч ускоренно через `update(1/60)` и делают скриншоты. Ошибки страницы печатаются как `PAGEERR`.
- Координаты: веб (x, y) = Unity (x, −z). Карта 120×120, центр в 0.
- `MPKA2_offline.html` — офлайн-файл для друга (открывается без интернета).

## Что уже сделано (кратко, по порядку)
Огр Mog → иконки предметов → бот на случайном герое → лобби как в Доте → 3 линии + лес → крепкие 2-е башни и глиф → Саня Финд с голосом (фраза смерти «Даже моя колбаска не вечна» = line5) → главное меню → 5 на 5 + туман войны → Макс Gold (фраза смерти = voice-message 9 = line6) → фиксы «герой тупит»/башни после разрушения → верхняя панель как в Доте → карточка героя + счёт на Ё → электричка в своём слоте (T) → пассивное золото, спокойное начало, денай → статистика У/С/П и добито/денаи → курьер с фото и тайник → всё это перенесено в веб-версию → курьеры у ботов (покупают вдали от бани в тайник и шлют курьера; без курьера идут в баню сами) + «Самокат курьеру» (боты берут после 3-й минуты); покупка в тайник теперь учитывает детали в инвентаре.
- **Сборка без Python:** Python на этом ПК не установлен (только заглушка Store), Node тоже — `build.py` можно повторить в PowerShell (склеить файлы в том же порядке, UTF-8 без BOM). Тесты Playwright без Node не запустить.
